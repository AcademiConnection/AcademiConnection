# AcademiConnection

面向 AI Agent 的学术关系网络探索工具。通过自然语言指令驱动，自动完成学者人脉查询、领域课题组调研、实验室深度画像等任务，结合 Web 搜索与 OpenAlex API 输出结构化报告。

## 功能

- **scholar-network** — 查询单个学者的合作者、导师、同门等学术关系
- **domain-survey** — 调研某研究领域内的主要课题组分布与代表工作
- **lab-profile** — 深度画像一个实验室：PI、学生、论文、合作网络、毕业去向

## 使用示例

Agent 提示词：

```text
> 请帮我查一下東雲つむぎ教授的学术合作网络

> 调研一下"縦連"领域有哪些主要课题组

> 请查一下奏坂高校マーチングポケッツ组的概况
```
